# AI and tool use disclosure

The project team used AI-assisted tools during development and documentation. Review this list and correct it to match the team’s complete use before submitting.

- **OpenAI Codex / ChatGPT** — assisted with code review, debugging, research summaries, documentation, and project packaging.
- **Roblox Studio MCP / Studio Assistant** — interacted with the Roblox Studio place, inspected the game, and supported gameplay capture. Roblox generation tools may have been used for some models; exact asset provenance must be checked in the Creator Dashboard and `game/manifest.json`.
- **Blender and FFmpeg** — used for the separate cinematic pipeline and video assembly; these are production tools, not generative AI by themselves.

No AI-generated live-game footage is represented as a cinematic render: the Moon and Mars gameplay clips were captured from the running Roblox Studio Play session.
